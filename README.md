# b8k-calendar

«Календарь» для планшета Lenovo YOGA Tablet 10 (B8000-H) с оболочкой
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux).

Календарь крупно, как настенный: сетка месяца с понедельника, выходные и праздники РФ красным, сегодня в синем круге, обзор года по касанию на названии месяца. Ничего не планирует и не хранит — только показывает даты.

Нужен только Python 3 с PyGObject (GTK 3); на другом компьютере работает так
же, без вибрации и вопросов в стиле оболочки. Установка: `sh install.sh [ROOT]`.
