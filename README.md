# calendar

«Календарь» среды [Haltia](https://github.com/haltia-de).

Календарь, как настенный: сетка месяца с понедельника, выходные и праздники РФ красным, сегодня в синем круге, обзор года по касанию на названии месяца. Ничего не планирует и не хранит — только показывает даты.

Нужен только Python 3 с PyGObject (GTK 3); на другом компьютере работает так
же, без вибрации и вопросов в стиле оболочки. Установка: `sh install.sh [ROOT]`.

Пакет и команда `haltia-calendar`. До ADR 0004 — `b8k-calendar`: старое имя
команды и скрытый `.desktop` старого id остаются до 3.0.
